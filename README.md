# Shinland

A personal portfolio built with React, TypeScript, Tailwind CSS, and Vite.

## Getting Started

### Requirements

- Node.js
- npm

### Installation

Install the project dependencies:

```bash
npm install
```

### Configure the contact form

Create a `.env.local` file in the project root and add your Formspree endpoint:

```env
VITE_FORMSPREE_ENDPOINT=your_formspree_endpoint
```

Replace the placeholder with your own endpoint. Keep `.env.local` out of Git.

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```

Vite generates the production build in `dist/`.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Privacy

Do not commit `.env.local`, credentials, private documents, or personal files you do not intend to publish. Review image assets before adding them to the repository.
